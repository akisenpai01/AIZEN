# **App Name**: Aizen Companion

## Core Features:

- Samurai AI Chat: Generate contextually appropriate and emotionally nuanced responses in the persona of a wise samurai, leveraging Google AI models via Genkit.
- Interactive Chat UI: A fully featured chat interface to communicate with the AI, and visualize all of Aizen's messages. Includes the capability to show the AI response in a speech bubble.
- Voice Selection: Voice selection to customize Aizen's voice. Voice settings should persist between sessions, if possible.
- Voice Input: Microphone input for voice-to-text functionality, allowing users to speak their messages. Microphone use indicated by a pulsating mic button.
- Voice Output: Text-to-speech functionality that reads Aizen's responses aloud. The speech can be customized.

## Style Guidelines:

- Primary color: Black (#000000) to reflect wisdom and strength.
- Background color: A dark gray (#333333) provides a subtle backdrop that emphasizes content and evokes the feeling of a dark yet refined samurai study.
- Accent color: White (#FFFFFF) is used for highlights and interactive elements. Use to provide contrast to the primary color.
- Consistent typography is present throughout the app, which must be accessible to facilitate communication.
- Use minimalist icons with a subtle outline style for a modern feel. Consider icons that evoke Japanese art when applicable.
- Fullscreen layout with a static samurai-themed background image visible through transparent UI elements.
